# Ergo Proxy (Revisited) (https://github.com/hfcf76-es-de), theme for [ES-DE](https://es-de.org/)

Ergo Proxy is a theme based/ported from the theme created by "Ryuuji" for the [RetroFE](http://retrofe.nl/) frontend, featuring some additional layouts for ES-DE.

## Configuration Options

- `Theme Aspect Ratios`: 16:9, 16:10, 19.5:10 and 4:3

- `Theme Variants`:

Carousel 1:
Carousel games with the selected item on the left

Carousel 2:
Carousel games with the selected item in the center

Carousel 3:
Carousel games with the selected item centered, featuring linear scaling down of the unselected items

- `Theme Color Schemes:`

Game Cover (Default):
Items in the carousel are game covers.

Game Cover (Default) [Rounded]: 
Carousel items are game covers with rounded corners

Game Cover (Aspect Ratio)
Carousel items are game covers, displayed in their original aspect ratio

Game Cover (Aspect Ratio) [Rounded]
Carousel items are game covers, displayed in their original aspect ratio with rounded corners

Game Cover (Stretch/Squash)
Carousel items are game covers, stretched or squashed for a uniform appearance

Game Cover (Stretch/Squash) [Rounded]
Carousel items are game covers, stretched or squashed for a uniform appearance, while featuring rounded corners

Game 3dbox
Carousel items are 3D game boxes

Game Media
Carousel items are the physical media of the games

Game Miximage
Carousel items consist of a screenshot, the physical media, and the game logo, all combined into a single image

Game Marquee
Items in the carousel are the game logos
